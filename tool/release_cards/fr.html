Pour la personne qui installe

  1. Recevez ce fichier d'une personne de confiance : le fondateur ou un administrateur.
  2. Sur Android, ouvrez l'APK. Si demandé, autorisez l'installation depuis votre gestionnaire de fichiers.
  3. Si le téléphone demande de désinstaller le myhanout existant d'abord — ARRÊTEZ. Cela signifie un certificat différent. N'installez pas.

Pour un administrateur avant de transmettre

  1. Intégrité : sha256sum -c SHA256SUMS
  2. Identité : apksigner verify --print-certs <apk> — l'empreinte SHA-256 doit égaler celle ci-dessus.
  3. Ou les deux à la fois : bash tool/verify_release_bundle.sh <dossier-du-kit>
  4. Transmettez le kit complet (APK + RELEASE.txt + SHA256SUMS + fiches), pas un APK isolé.
