For the person installing

  1. Get this file from a person you trust — the founder or an administrator.
  2. On Android, open the APK. If asked, allow installation from your file manager.
  3. If the phone asks you to uninstall the existing myhanout first — STOP. That means the certificate is different. Do not install.

For an administrator before forwarding

  1. Check integrity: sha256sum -c SHA256SUMS
  2. Check identity: apksigner verify --print-certs <apk> — the SHA-256 digest must equal the fingerprint above.
  3. Or check both at once: bash tool/verify_release_bundle.sh <kit-folder>
  4. Forward the whole kit (APK + RELEASE.txt + SHA256SUMS + cards), not a lone APK.
